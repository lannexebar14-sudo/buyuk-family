# BUYUK FAMILY — Site vitrine

Site vitrine responsive de BUYUK FAMILY KEBAB à Condé-en-Normandie, prêt pour Vercel.

## Déployer sur Vercel

Ce dépôt GitHub est prêt à être importé dans le compte Vercel **mamboflye**.

1. Ouvrez [Vercel — Nouveau projet](https://vercel.com/new/mamboflye).
2. Dans **Import Git Repository**, cherchez et importez `lannexebar14-sudo/buyuk-family`. Si GitHub n'apparaît pas, configurez l'accès GitHub depuis Vercel.
3. Nommez le projet `buyuk-family`, choisissez **Other** si Vercel demande un framework, conservez le répertoire racine `./`, n'ajoutez **aucune commande de build** et **aucune variable d'environnement**.
4. Cliquez sur **Deploy**. Vercel hébergera le site statique et générera une URL `*.vercel.app`.

Une fois le dépôt lié, les prochains commits sur `main` déclencheront automatiquement de nouveaux déploiements.

## Fichiers

- `index.html` — page d'accueil
- `styles.css` — design responsive
- `app.js` — carte interactive et menu mobile
- `assets/` — favicon et aperçu graphique
- `manifest.webmanifest` — identité web
- `vercel.json` — en-têtes de sécurité et configuration

**Important :** photographies illustratives ; horaires, tarifs, produits réellement proposés, numéro de téléphone et réseaux sociaux doivent être confirmés par le restaurant avant diffusion officielle. Aucune commande ni aucun paiement en ligne.
