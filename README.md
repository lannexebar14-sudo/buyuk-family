# BUYUK FAMILY — Site vitrine

Site du restaurant BUYUK FAMILY KEBAB à Condé-en-Normandie. Site statique responsive, sans build, destiné à Vercel. La sélection des plats et les horaires sont indicatifs et doivent être validés avec l'établissement avant publication.

## Mise en ligne
Importer ce dépôt GitHub sur Vercel avec Framework Preset `Other`, répertoire racine `./`, sans commande de build ni répertoire de sortie forcé.

Le site propose une carte interactive, les informations de contact et un bouton pour appeler le restaurant. Il ne permet ni commande ni paiement en ligne.
